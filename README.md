# 📊 Investment Preference Analysis – Power BI Project

## 📌 Project Overview

The **Investment Preference Analysis** project focuses on understanding individual investment preferences, financial goals, and investment behaviour using Microsoft Power BI.

The objective of this project is to analyse how individuals choose different investment avenues based on their preferences, savings objectives, risk considerations, investment duration, and expected returns.

Through interactive dashboards and data-driven insights, this project helps identify investment trends and understand the factors influencing financial decisions.

## 🎯 Project Objectives

- Analyse the most preferred investment avenues.
- Understand investment behaviour across different age groups and genders.
- Explore investors' savings objectives and financial goals.
- Identify the relationship between investment preferences and investment reasons.
- Analyse investment duration and monitoring frequency.
- Understand the factors influencing investment decisions.
- Generate meaningful insights to support better financial understanding.

## 📂 Dataset Description

The project uses investment-related survey data containing information about respondents, their demographics, financial objectives, and investment preferences.

**Key areas covered in the dataset:**

- Age Group and Gender
- Investment Avenue
- Investment Objective
- Savings Objectives
- Investment Duration
- Monitoring Frequency
- Expected Returns
- Investment Information Sources
- Factors Influencing Investment Decisions
- Reasons for Choosing Investment Avenues

## 🔄 Data Preparation & Transformation

The following steps were performed during data preparation:

- Imported the dataset into Power BI.
- Reviewed the dataset structure and data types.
- Cleaned and transformed data using Power Query.
- Unpivoted investment preference columns to create a structured investment preference table.
- Renamed columns for better understanding and analysis.
- Created calculated measures using DAX.
- Prepared data for interactive visualizations.

## 📈 Dashboard Analysis

The project explores investment behaviour through multiple analytical tasks.

### 1. Investment Preference Overview
- Total respondents
- Average age of respondents
- Most preferred investment avenue
- Investment preference distribution
- Investment objectives and savings goals

### 2. Demographic Analysis
- Gender-wise investment comparison
- Age-wise investment behaviour
- Investment preferences across different demographic groups

### 3. Investment Behaviour Analysis
- Investment avenue by savings objective
- Investment duration analysis
- Monitoring frequency versus investment preferences
- Investment preferences across different categories

### 4. Investment Factors & Reasons Analysis
- Factors influencing investment decisions
- Investment reasons across different investment types
- Distribution of investment reasons
- Comparison of investment preferences and reasons

### 5. Preference Ranking Analysis

Analysed the ranking of seven investment avenues to understand which options respondents ranked more favourably.

**Important:** Preference ranking represents respondents' stated preferences, not actual investment amounts or purchase transactions.

- Which financial objectives influence investment choices.
